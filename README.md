# Expense Tracker 💰

К онсольное приложение на Python и SQLite для удобного учета личных финансов.

## 🚀 Функционал
- ➕ Добавление новых трат (сумма, категория, описание)
- 📊 Просмотр списка всех расходов
- 📈 Подсчет общей суммы и аналитика по категориям

## 🛠 Технологии
- **Python 3.x**
- **SQLite3** (*база данных*)
- **Git / GitHub**
